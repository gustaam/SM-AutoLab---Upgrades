# SM AutoLab v2.66

Base: v2.65 corrigida.

Alterações desta versão:
- contador da planilha passa a contar linhas preenchidas, e não células;
- histórico de planilhas passa a se chamar “Arquivos”;
- arquivos históricos permanecem por 30 dias, sem limite de quantidade;
- novo botão “Limpar histórico” e X individual para apagar cada arquivo;
- status do cabeçalho fica “Finalizado” por 10 segundos ao concluir e retorna para “Pronto”;
- o sistema de atualização pelo GitHub permanece preservado.
